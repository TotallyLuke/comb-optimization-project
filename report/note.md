This project aim to develop and compare two optimization algorithms for
 solving the Travelling Salesperson Problem (TSP) in the context of 
 minimizing the time required to drill holes in a printed circuit board.


We make the assumption that for every hole in the same board the same tool
is used. This simplifies the problem by removing variables like tool changes.  
The only variable being optimized is the time required to move the tool.
 We further assume that when the tool is moving, it is moving at a constant 
 velocity: Hence the time to move the drill is directly proportional to the 
 toolpath length.
